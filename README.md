# Vermont Policing Data: Exploratory Data Analysis (EDA)

## Project Overview

This project explores policing data from Vermont to identify patterns, trends and potential disparities in law enforcement activity. Using exploratory data analysis (EDA), the project examines police interactions, demographic characteristics, search practices and other available variables to better understand how policing activities vary across different groups, locations and time periods.

The objective is to transform raw policing data into meaningful insights through data cleaning, statistical analysis and visualization.

## Objectives

* Assess the structure, quality and completeness of the dataset.
* Identify trends and patterns in policing activity over time.
* Examine demographic distributions across recorded police interactions.
* Investigate differences in search rates and other policing outcomes across demographic groups, where the necessary variables are available.
* Explore variations in policing activity across agencies, locations or other relevant categories.
* Communicate findings through clear statistical summaries and visualizations.

## Ethical Considerations and Limitations

Policing data may reflect differences in reporting practices, enforcement policies and data collection procedures. Recorded encounters do not necessarily represent the underlying incidence of criminal activity or the experiences of an entire population.

This analysis is exploratory and descriptive. Observed differences should not automatically be interpreted as evidence of discrimination, causation or individual misconduct.
